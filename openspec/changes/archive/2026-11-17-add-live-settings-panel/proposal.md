# Proposal

## Why

当前配置散落在 Tampermonkey 菜单和源码常量中，菜单修改后多个功能仍沿用初始化快照，本地标签开关及全部重置还依赖刷新页面。需要一个统一的配置面板，覆盖已有功能配置和有效运行路径上的可调数值，让用户保存后即可使用新配置。

## What Changes

- 通过 Tampermonkey 的“设置”菜单打开页面右下角的配置面板；配置按作品预览（含作品下载）、作品排序、本地标签划分。
- 将缓存、下载记录与跨标签页协调、网络请求、内部调度等底层数值纳入默认隐藏的“高级设置”，只有用户点击后才展示。
- 保留现有 13 个配置字段的功能语义，补充非外观的行为和性能数值；原菜单中“插画作品预览”改为准确表达整个预览功能的总开关。
- 面板编辑、单项恢复默认和全部恢复默认只改变草稿；保存时统一校验、持久化并应用；关闭放弃未保存修改。
- 保存后无需刷新：功能开关及交互立即更新，排序参数从下一次手动排序起使用，网络及调度参数从下一次对应操作起使用；不因保存自动抓取作品或中断进行中的任务。
- 缓存容量变小后按新上限淘汰缓存；全部恢复默认不删除本地标签、下载记录，也不重置内部版本元数据。
- **BREAKING**：移除原有逐项切换、prompt 输入和立即重置并刷新页面的配置菜单路径；不保留双入口或旧配置迁移层。
- 不开放外观参数，不配置协议、格式、站点分页语义常量；派生值按配置计算，不将过时浏览器兼容分支转成配置项。

## Capabilities

### New Capabilities

- `settings-panel`: Tampermonkey 入口、功能分组、默认隐藏的高级设置，以及草稿编辑、校验、保存和恢复默认的交互。
- `runtime-settings`: 配置字段及默认值、有效参数边界、持久化和多标签页同步，以及各功能无需刷新地采用新配置的规则。

### Modified Capabilities

无。当前 `openspec/specs/` 尚无已有能力规格。

## Impact

- 入口与配置：`src/index.ts`、`src/utils/setting.ts`、`src/constants/index.ts`、`src/types/index.ts`、`src/i18n/index.ts`；新增独立配置面板及字段清单模块。
- 功能：`src/features/preview.ts`、`src/features/sort.ts`、`src/features/local-tags.ts`；调整初始化快照、功能启停和事件/观察器清理。
- 底层：缓存数据库访问、下载记录服务、请求重试、标签缓存、LRU、DOM 探测及动图播放器中的有效可调参数。
- 文档：更新 README 的配置定位、分组、生效时机和缓存默认策略表；所有界面文案保持中文。
- 复用 jQuery、GM 存储及已有 GM 变更监听授权，保持 Chrome >= 107；不计划增加运行依赖、网络权限或配置导入导出。
- 本变更仅生成规划文档；实现阶段不得无故提升版本、生成发布构建或修改已跟踪的 `dist/`。
